⚡ Préparation des envois automatiques
Ces réglages préparent les futurs envois automatiques. Tant que le moteur d'automatisation n'est pas activé, aucune activation ci-dessous ne déclenche un courriel.
Envoi automatique à la création
Prévoit l'envoi du premier message après une création manuelle.
Envoi automatique après import
Prévoit l'envoi du premier message pour les contributions importées.
Relances automatiques
Prévoit un envoi lorsque la contribution répondra aux règles de relance.
🧩 Variables disponibles
Une ligne contenant une variable vide est automatiquement masquée dans le message final. Par exemple, Description : [DESCRIPTION] disparaît si aucune description n'est renseignée.
Cliquez sur une variable pour l'insérer dans le champ que vous êtes en train de modifier.
