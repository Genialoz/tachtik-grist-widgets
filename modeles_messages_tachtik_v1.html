✉️ Modèles de messages

Personnalisez les messages utilisés par Tâchtik pour chaque bureau d'origine. Les modèles sont enregistrés dans PARAMETRES_BUREAUX.

⚙️ Paramétrage

Une ligne contenant une variable vide est automatiquement masquée dans le message final. Par exemple, Description : [DESCRIPTION] disparaît si aucune description n'est renseignée.
Cliquez sur une variable pour l'insérer dans le champ que vous êtes en train de modifier.

👁️ Aperçu du modèle

Objet
L'aperçu utilise des exemples. Lors d'un vrai envoi, Tâchtik remplace ces variables par les données de la contribution.
