Cette page est réservée aux utilisateurs ayant le rôle Administrateur.

1. Choisir le bureau et le fichier Excel

Le bureau sélectionné sera appliqué à toutes les contributions du fichier.

Le fichier doit contenir une feuille Import avec les colonnes : Titre, Description, Demandeur, Niveau_contributeur, Contributeur, Echeance, Priorite, Statut, Commentaire, Groupe.
Niveau_contributeur doit contenir : Département, Sous-direction ou Service. Pour Contributeur, utilisez le code correspondant au niveau choisi.
Groupe est facultatif : répétez la même valeur sur plusieurs lignes pour créer plusieurs affectations rattachées à une même demande.
Les contributions existantes du bureau demandeur sélectionné sont automatiquement détectées et mises à jour lorsqu'une correspondance unique est trouvée. Les doublons ambigus sont ignorés sans bloquer le reste du fichier.
